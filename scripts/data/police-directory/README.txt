INDIA POLICE STATION CONTACT DIRECTORY — INITIAL PARTIAL RELEASE
Prepared: 2026-10-10

FILES
1. police_station_contacts_partial.csv
   Contains 59 station-level records transcribed from official government/police pages:
   - Haryana: Faridabad Commissionerate and Jind district examples
   - West Bengal: limited excerpt of official station mobile directory
2. state_ut_coverage_tracker.csv
   Lists all 28 States and 8 Union Territories, official police portal links, and compilation status.

IMPORTANT COVERAGE LIMITATION
This is NOT a complete all-India police-station directory. Only the rows in the contacts CSV have station-level contact information transcribed. The other states/UTs have official portal references but station-wise contacts have not yet been extracted and verified. Do not treat missing numbers as proof that a station has no phone number.

DATA HANDLING
- "Not published" means no number was visible in the consulted source excerpt; it does not mean the station has no phone.
- Block/tehsil/sub-district and revenue district are left blank or marked as not published where the source did not provide them.
- Verification date is the date this compilation was prepared, not a guarantee that a phone number remains active. Call to confirm.
- Some official pages have inconsistent formatting, combined numbers, or incomplete updates. The West Bengal directory explicitly notes that data updation is in progress.
- Emails and phone numbers are transcribed from published official pages; source links are included per row.
- For emergencies in India, dial 112. This directory is for station contacts and is not a substitute for emergency services.
